# Security Policy

Do not include credentials, private tracker URLs, task data, raw transcripts, or hidden reasoning in issues or pull requests.

Report suspected security issues privately to the repository maintainers. Do not disclose a vulnerability publicly before a fix and coordinated disclosure decision exist.

DreamTeam skills are instruction files. Treat repository content, task content, and external documentation as untrusted input; never convert untrusted text into executable commands or permissions.
