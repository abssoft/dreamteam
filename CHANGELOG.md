# Журнал изменений dream-team

Заметные изменения плагина `dream-team`, новые сверху, в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/): `## [X.Y.Z] - ГГГГ-ММ-ДД`, затем по одному пункту на изменение — что видит вызывающая сторона (обёртка или человек), а не какие файлы тронуты; ломающее изменение начинается с `**Breaking:**`. Каждое повышение версии добавляет запись сверху: `npm test` падает, пока верхняя запись отстаёт от `package.json`. `dream-team:changelog` печатает последние записи.

## [4.2.0] - 2026-09-03

- Скилл `changelog`: печатает последние записи этого файла (по умолчанию 10, `--last=N`) — что нового в установленной версии; установленный плагин git-истории не несёт.

## [4.1.0] - 2026-09-03

- `agent-usage`: `launches: [{rootAgentRef, label}, …]` рендерит несколько завершённых запусков одной таблицей «Затрачено» с одним точным ИТОГО и объединённым рабочим временем; обёртки вызывают его один раз перед финальным отчётом.

## [4.0.0] - 2026-09-03

- **Breaking:** `product-technologist` стал интерактивным: работает в процессе обёртки без Assignment v1 / Result v1, опрашивает пользователя по раундам, исследует репозиторий read-only детьми и отдаёт документ PRD и заголовок задачи в контексте.
- Канон документа: Проблематика + Продуктовое решение с фиксированными H3-разделами; `software-developer` отвечает за техническое проектирование, когда ТЗ не передано.

## [3.3.0] - 2026-09-01

- `agent-usage`: ячейки `$` в таблице усекаются до трёх знаков; точные суммы остаются в машинных полях.

## [3.2.0] - 2026-09-01

- `agent-usage`: таблица от входа — Время · Шаги · Токены всего · В т.ч. кэш · Выход · $; сумма вход+выход больше не рендерится, колонка денег называется `$`.

## [3.1.0] - 2026-09-01

- `agent-usage`: всегда нулевая колонка «В кэш» убрана; поток Codex без записанного тарифа считается как Standard; корзины без запросов не рендерятся.

## [3.0.0] - 2026-09-01

- **Breaking:** `agent-usage` по умолчанию печатает только готовые строки; машинные поля — по `full: true`.
- `agent-usage`: точный реестр запросов (без кэша / чтение кэша / запись кэша / выход) по официальным тарифам за токены с учётом тарифного плана; статус `pricing` закрыт при любой неопределённости.
- `product-technologist`: чётче граница продуктового решения и ТЗ — Проблема/Решение/Не делаем подтверждает владелец продукта, проверяемые QA детали уходят в ТЗ, замороженные решения не пересматриваются.

## [2.2.0] - 2026-08-28

- `agent-usage`: опциональный `analyze` относит рост контекста к результатам инструментов и выдаёт вердикт по стоимости в `rendered.analysis_block`; точные итоги не меняются.

## [2.1.1] - 2026-08-27

- `agent-usage`: строки сабагентов Codex получают читаемые имена стадий вместо сырых путей.

## [2.1.0] - 2026-08-27

- `agent-usage`: по строке на запуск × модель — сабагенты видны в таблице и в `comment_html`; новое поле `by_launch`.

## [2.0.2] - 2026-08-27

- `agent-usage`: рабочее время суммирует реальные ходы (маркеры задач Codex, в Claude — от сообщения пользователя до последней рабочей записи), объединение по параллельным сабагентам.

## [2.0.1] - 2026-08-27

- **Breaking:** роль `technical-writer` и её deliverable `documentation_proposal` удалены; документацию ведут обёртки.
- `agent-usage`: рабочее время считает только активную работу — простои дольше 30 минут исключаются.
