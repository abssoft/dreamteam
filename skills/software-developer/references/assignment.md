# Developer assignment reference

The wrapper provides one Assignment v1 packet with opaque `workspace_ref`, `revision_ref`, and `base_ref`, safe relative navigation evidence, accepted decisions, exact Scope, and QA checklist. It prepares the authorized process cwd out-of-band. The developer may read and change repository files only within that authority; it neither requires nor returns a serialized workspace, branch, raw revision, or tracker coordinate. Tracker and Git lifecycle operations remain outside this role.
